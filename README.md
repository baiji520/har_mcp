# har-mcp

一个 MCP 服务器，让 AI agent 能够读取和分析 HAR（HTTP Archive）抓包文件。

浏览器导出的抓包动辄几十上百 MB，整份塞进上下文既不现实也不划算。`har-mcp`
把分析拆成十四个细粒度工具，agent 可以先看整体概况，再按域名、路径、状态码
缩小范围，最后只读取需要的那一条请求的头部或响应体。每次回答都控制在几 KB
以内。

## 有什么用

- **摸清一个抓包里有什么**：条目数、状态码分布、访问了哪些域名、最慢和最大的请求
- **找接口**：列出所有去重后的端点，附带调用次数、方法、状态码和平均耗时
- **读单条请求**：查看某条请求的头部、请求体、响应体，JSON 自动美化
- **在载荷里搜索**：正则匹配请求或响应内容，定位哪个请求带着某个 token 或字段
- **复现请求**：生成可直接执行的 curl 命令
- **导出与脱敏**：只保留符合条件的条目，可选清洗掉 token、cookie、密码等敏感值
- **校验文件**：确认一个文件是否真的是合法 HAR

纯 Go 标准库实现，无第三方依赖。

## 安装

无需安装。服务器直接从 GitHub 运行，Go 会在首次启动时拉取并编译。

在 MCP 客户端配置中加入：

```json
{
  "mcpServers": {
    "har-mcp": {
      "command": "go",
      "args": [
        "run",
        "github.com/baiji520/har_mcp/cmd/har-mcp@main"
      ]
    }
  }
}
```

要求机器上装有 Go 1.24+，且首次启动时能访问 Go module proxy。

`go run` 只编译一次，之后走构建缓存，启动很快。要锁定版本，把 `@main` 换成
tag 或 commit，例如 `@v1.1.0`。

## 使用

配置好后直接让 agent 分析抓包，例如：

```
用 har-mcp 看看 /path/to/capture.har 里有哪些接口
```

所有工具都通过 `file` 参数接收抓包文件的绝对路径，一个服务器实例可以服务任意
多个 HAR 文件。
